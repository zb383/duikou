# 04 · 竞品与商业分析

> 变现逻辑 + 竞品格局 + 差异化护城河。

---

## 一、变现逻辑

学生群体付费能力弱,因此设计为 **免费 + 小额额度**,而非订阅制收大钱:

| 层次 | 策略 | 说明 |
|------|------|------|
| 免费 | 注册送几次「JD 解析 + 改简历」额度 | 让用户先体验出效果,戳中痛点 |
| 付费 | 超出额度后按次 ¥2 或包月 ¥9.9 | 小额,契合学生支付能力 |
| 付费点 | 「一键导出改好的 Word/PDF」 | 价值感知最强,最适合作为付费动作 |

**核心逻辑**:先让用户靠免费额度「看到自己简历差在哪」,痛点被戳中后,自然愿意为「一键改好 + 导出」付小钱。

## 二、竞品格局

市面帮人改简历的产品大致分三类,各有没做好的地方:

| 类型 | 代表思路 | 它们没做好的地方 |
|------|---------|----------------|
| 通用 AI | 把 JD + 简历丢给 ChatGPT/豆包直接改 | 用户还是得**自己看懂 JD 要什么、自己判断改没改对**(正好是本产品的痛点 1 和 3) |
| 简历模板工具 | 超级简历、职徒简历等 | 擅长「从零排版/套模板」,但**不针对某一家公司的 JD 做精准适配** |
| 海外面向求职 | Resume Worded、Teal、Rezi | 英文/海外市场为主,国内校招实习场景、JD 风格对不上 |

## 三、差异化护城河:一个闭环

单点工具都做不了的是**闭环**:

```
针对「我正要投的这家公司」
   → 解析 JD 要什么
   → 诊断我简历差在哪
   → 精准改
   → 导出 Word/PDF
   → 投递后记录
   → 复盘「为什么被拒」
   → 反哺下一版简历怎么改
```

「改简历」和「投递复盘」**打通**才是护城河,而不是又一个「帮你改简历」的 AI 壳子。

## 四、风险与应对

| 风险 | 说明 | 应对 |
|------|------|------|
| 大模型 API 成本 | 每次诊断/改写都有 token 成本 | 免费额度设上限,付费覆盖成本 |
| 通用 AI 竞争 | 用户可能直接问 ChatGPT | 靠「针对单家 JD 的差异诊断 + 闭环」做差异化,而非泛泛改写 |
| 学生付费能力弱 | 单价低 | 走量 + 小额高频,后期接广告/内推分成 |
| 简历隐私 | 含个人信息 | HTTPS 加密传输 + 加密存储,不将数据用于模型训练(需确认 API 条款) |
