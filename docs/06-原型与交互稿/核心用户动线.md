# 核心用户动线(交互流程图)

> 对应 PRD 第 3 节。展示用户从上传简历到完成投递记录的完整路径,含异常分支。

```mermaid
flowchart TD
    A[用户进入首页] --> B[上传简历 PDF/Word]
    B --> C{简历解析是否成功?}
    C -->|失败: 扫描件/格式不支持| C1[引导手动粘贴或重新上传]
    C1 --> B
    C -->|成功| D[用户添加投递目标: 公司+岗位+JD+截止日期]
    D --> E[系统解析 JD 能力要求]
    E --> F[生成简历差异诊断报告]
    F --> G{用户是否满意诊断?}
    G -->|不满意| G1[重新生成诊断]
    G1 --> F
    G -->|满意| H[AI 精准改写简历]
    H --> I[用户微调/确认]
    I --> I1[导出 Word / PDF]
    I --> J[保存为投递记录到看板]
    J --> K[设置截止提醒]
    K --> L[投递后更新状态 / 记录结果]
```

## 关键异常分支说明

| 分支 | 触发 | 处理 |
|------|------|------|
| 简历解析失败 | 扫描件 / 格式不支持 | 引导手动粘贴或重新上传 |
| 诊断不满意 | 用户对结果有异议 | 重新生成诊断 |
| 无真实经历可改写 | 简历缺对应能力 | 标注「⚠️ 无法改写」,不编造 |
