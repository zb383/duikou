# 02 · 产品概念文档(第一版)

> 概念版的唯一目的是**对齐方向**——不展开细节,让用户在无信息噪音的情况下快速判断「方向对不对」。

---

## 一句话定位

> 这是一个给**找实习 / 校招的学生**用的**网页 Web App**,帮他们把「盲投 + 手动改简历」变成「看懂 JD → 精准改简历 → 投递后复盘」的可持续求职流程。
> 与现有方案相比,核心差异是:**把「改简历」和「投递复盘」打通成一个闭环**,而不是又一个单点的 AI 改简历工具。

## 产品形态

- **当前选型**:网页 Web App
- **选择理由**:开发者靠 AI 辅助(能看懂代码但不写),Web 是 AI 最易一次性生成、本地可快速验证的形态;学生手机/电脑都适用;开发链路最短,符合 MVP 优先原则。
- **阶段策略**:先做 Web 版验证「学生是否愿意为精准改简历付费」,跑通后再考虑微信小程序(承接学生流量与社交传播)。

## 目标用户

- **核心画像**:找实习的在校生(大二~大四)与应届校招生,现在用 Excel / 微信记投递,或干脆不记;简历只有一份通用版,对不同公司「一套简历走天下」。
- **核心痛点**:改简历太麻烦——最痛是「不知道 JD 到底要什么、不知道自己简历哪里对不上」,其次是「知道改哪但手动改太费劲」,最后是「改完不确定这版投这家行不行」。
- **为什么选它**:现有方式(Excel 记录 + 手动改简历 + 盲投)解决不了「看不懂 JD、改没改对」的问题;他们需要的是针对「正要投的这家公司」的精准适配,而不是又一个模板工具。

## 产品价值

- **用户价值**:少走弯路——知道该投哪些、简历差在哪、怎么改、投完为什么被拒,把求职从「碰运气」变成「可优化」。
- **商业价值 / 变现逻辑**:免费 + 小额额度。注册送几次「JD 解析 + 改简历」额度戳中痛点;超出后小额付费(按次 ¥2 或包月 ¥9.9);「一键导出改好的 Word/PDF」作为价值感知最强的付费点。

## 核心功能方向(只列方向,不展开细节)

- **改简历(核心)**:针对具体 JD 解析能力要求 → 诊断简历差异 → 精准改写
- **投递看板**:集中记录投递的公司、岗位、状态、进度
- **截止提醒**:投递截止日期提醒,不错过机会

## 不做什么(边界)

- ❌ 不做「自动海投 / 一键群发」——信任风险高,且违背「精准投递」的产品理念
- ❌ 不做「从零创作简历 / 模板市场」——那是超级简历等工具的主战场,本产品聚焦「针对已有简历做 JD 适配」
- ❌ 不做「求职社区 / 内推社交」——超出当前核心痛点
- ⏸ 第一版暂不做:JD 关键词匹配(独立模块)、每周复盘、导出 Word/PDF(作为付费点放后续迭代)
- ⏸ 当前阶段不做原生 App / 小程序

## 待确认问题(已确认结果)

- ✅ 简历导入方式:上传 PDF / Word(也支持粘贴文本)
- ✅ 大模型:DeepSeek
- ✅ 登录方式:手机号验证码登录
- ✅ 产品名称:对口(取自「专业对口 / 能力对口」)
